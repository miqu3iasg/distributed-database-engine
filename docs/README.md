# Documentation Map

Where every documentation file lives, and where a new one goes. For _how_ to write them, see [`guides/documentation-guidelines.md`](./guides/documentation-guidelines.md).

## Layout

```
geodb/
├── README.md                      Entry point: architecture, guarantees, honest limitations (to be written)
├── AGENTS.md                      Rules for AI coding agents (source of truth)
├── CLAUDE.md                      Claude Code additions; imports AGENTS.md
├── CONTRIBUTING.md                How to contribute and where each request goes
├── GLOSSARY.md                    Shared vocabulary
├── .github/
│   ├── PULL_REQUEST_TEMPLATE.md   PR template
│   └── ISSUE_TEMPLATE/
│       ├── config.yml             Issue chooser (blank issues off, contact links)
│       ├── bug.yml
│       ├── feature.yml
│       ├── adr-proposal.yml
│       ├── documentation.yml
│       └── verification-gap.yml
├── docs/
│   ├── README.md                  This map
│   ├── overview/
│   │   ├── general-description.md       High-level description (pt-BR)
│   │   └── technical-specification.md   Technical specification (pt-BR)
│   ├── adr/                       Architecture Decision Records
│   │   └── adr-NNNN-<slug>.md
│   ├── templates/
│   │   └── adr-template.md        ADR template
│   ├── guides/
│   │   ├── commit-guidelines.md
│   │   ├── pull-request-guidelines.md
│   │   ├── documentation-guidelines.md
│   │   └── testing-guidelines.md
│   ├── bugs/                      One write-up per bug found
│   │   └── NNNN-<slug>.md
│   └── EVIDENCE.md                Generated by CI; never edited by hand
├── specs/tla/                     TLA+ specifications
├── sim/corpus/                    Regression seeds (replayed on every commit)
└── ops/grafana/                   Versioned dashboards
```

## Where each file goes

| File                                      | Location                                   | Language | Notes                                                                   |
| ----------------------------------------- | ------------------------------------------ | -------- | ----------------------------------------------------------------------- |
| Project entry page                        | `README.md`                                | en-US    | Architecture, guarantees, limitations, one-command reproducible results |
| Agent rules                               | `AGENTS.md`, `CLAUDE.md`                   | en-US    | Repo root. `CLAUDE.md` starts with `@AGENTS.md`                         |
| Contribution guide                        | `CONTRIBUTING.md`                          | en-US    | Repo root (GitHub detects it)                                           |
| Glossary                                  | `GLOSSARY.md`                              | en-US    | Repo root. Update when a term is added or renamed                       |
| General description                       | `docs/overview/general-description.md`     | pt-BR    | Lowest precedence when documents disagree                               |
| Technical specification                   | `docs/overview/technical-specification.md` | pt-BR    | Items marked **[ADR]** need an ADR before implementation                |
| ADR                                       | `docs/adr/adr-NNNN-<slug>.md`              | en-US    | Four-digit number, never reused; immutable once accepted                |
| ADR template                              | `docs/templates/adr-template.md`           | en-US    | Copy into `docs/adr/` to start an ADR                                   |
| Commit, PR, documentation, testing guides | `docs/guides/`                             | en-US    | One file per workflow                                                   |
| PR template                               | `.github/PULL_REQUEST_TEMPLATE.md`         | en-US    | GitHub pre-fills it on every PR                                         |
| Issue templates                           | `.github/ISSUE_TEMPLATE/*.yml`             | en-US    | Plus `config.yml` for the chooser                                       |
| Bug write-up                              | `docs/bugs/NNNN-<slug>.md`                 | en-US    | Seed, root cause, fix, regression, lesson                               |
| Evidence ledger                           | `docs/EVIDENCE.md`                         | en-US    | Generated by CI                                                         |
| Formal specs                              | `specs/tla/`                               | n/a      | Referenced from code comments                                           |
| Regression seeds                          | `sim/corpus/`                              | n/a      | Never delete a seed                                                     |
| Dashboards                                | `ops/grafana/`                             | n/a      | Versioned with the code                                                 |

Precedence when documents disagree: **ADR > technical specification > general description**.

## Quick rules for a new document

| You are writing                          | Put it in                                                 |
| ---------------------------------------- | --------------------------------------------------------- |
| A decision with real alternatives        | `docs/adr/` (copy `docs/templates/adr-template.md`)       |
| A change to scope, structure, or roadmap | `docs/overview/technical-specification.md`                |
| A contributor workflow or convention     | `docs/guides/`                                            |
| A reusable template                      | `docs/templates/` (GitHub-specific ones go in `.github/`) |
| The story of a bug you found             | `docs/bugs/`                                              |
| A new term                               | `GLOSSARY.md`                                             |
| Rules an agent must follow               | `AGENTS.md` (Claude-only additions in `CLAUDE.md`)        |

## Notes on moving the existing files

- The ADRs were renamed from timestamped Obsidian names (`adr-20261122-...-001-...md`) to `adr-NNNN-<slug>.md` to match their `path` front-matter field, and their `[[wikilinks]]` were updated.
- The overview and specification have timestamped names too and link to each other by old names (for example `GeoDB-visao-geral.md`). Rename them as in the layout above and fix those links.
- Keep front matter on every markdown file under `docs/`, with `path` matching the real location.
